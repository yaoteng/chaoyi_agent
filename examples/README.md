# 示例（Examples）

本目录收录「社区 agent 化」的真实改造样例，作为 Skill 库的**活文档与 demo**。

| 目录 | 说明 |
|---|---|
| [reference-community](reference-community/README.md) | 一个 2.3k star 的 Rust 工具库社区，如何用潮驿 5 个 Skill 把月度运营工时从约 40h 压到约 6h（含 before/after 与可直接复制的调用话术） |

> 你也可以用自己维护的社群跑一遍，把改造记录 PR 进来，作为新的示例——这正是「社区 agent 化」飞轮的一部分。
