# 经销商入驻引导（Distributor Onboarding）

## When to use
- 新经销商 / 二批商 / 加盟门店完成签约，需要启动入驻流程。
- 招商团队希望把"签约后靠人盯"的零散动作标准化为流水线。
- 发现新客户首单周期过长、资料反复补交、培训没人跟。
- 季度复盘显示新经销商首月动销率低于阈值。

## Steps
1. **盘点现有 SOP**：读取既有入驻制度、合同模板、系统开通步骤，识别「卡在哪一环」。
2. **生成分层入驻清单**：按角色拆成 4 级——① 资质收集（营业执照 / 授权 / 银行账户）→ ② 系统开通（账号 / 价格体系 / 客户档案）→ ③ 培训（产品 / 下单 / 政策）→ ④ 首单激励（首单满减 / 返点 / 赠品）。
3. **起草资质收集表**：给出字段清单与校验规则（税号格式、授权链路完整性），减少来回补件。
4. **生成欢迎与首单引导话术**：分渠道（企微 / 短信 / 电话）写欢迎语，并明确首单激励的领取路径与时效。
5. **产出接入清单**：列出需商务 / 财务 / 系统管理员手动确认的项（如授信额度、特价审批）。

## Output
- 一份《入驻阶梯》Markdown（含各级步骤、责任人、预计耗时）。
- 一张资质收集表（字段 + 校验规则 + 样例）。
- 两段欢迎 / 首单引导话术（企微 + 短信）。
- 一份「待商务确认」清单（HITL）。

## Guardrails
- 只出草稿与建议，**不**自动外发短信、不替代签约与法务动作，需商务确认。
- 资质含敏感信息（执照、账户），仅用于本次入驻，不外泄、不留存于对话之外。
- 首单激励涉及真金白银，金额 / 门槛需商务复核，不得臆造政策。

## Notes
- 可配合 `reach-campaign` 联动：入驻欢迎与首单催办走统一的多渠道触达编排。
- 适用于经销商 / 二批 / 门店三种形态，按层级差异调整清单颗粒度。
