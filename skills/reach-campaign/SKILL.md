# 多渠道触达编排（Reach Campaign）

## When to use
- 新品上市、促销政策、价格调整需要批量通知下游经销商。
- 月末 / 季末回款催办，需分层触达不同账期客户。
- 动销低迷，要针对低活跃客户发起唤醒。
- 招商活动需要按区域 / 层级定向邀约。

## Steps
1. **明确目标与人群**：从请求中提取目标（通知 / 宣贯 / 激励 / 催办）、人群分层维度（区域、层级、动销、账期）。
2. **设计多波次节奏**：典型 3 波——① 预热（政策剧透 / 悬念）→ ② 正式（完整政策 + 行动指引）→ ③ 跟进（未读提醒 / 答疑）。
3. **逐渠道生成话术**：
   - 微信 / 企微：可长文，带政策要点 + 链接 + 截止时间。
   - 短信：≤ 70 字，前 15 字说清「谁 + 什么事 + 动作」。
   - 电话：只给要点提纲（开场 / 核心诉求 / 异议处理 / 收尾）。
4. **给出发送窗口与频率上限**：避开深夜；同客户 24 小时内同渠道 ≤ 1 次；重大政策可跨渠道但需去重。
5. **产出待确认排期**：生成《触达排期表》，标注每波时间、渠道、人群、负责人，交由商务确认后执行。

## Output
- 《触达排期表》Markdown（波次 × 渠道 × 人群 × 话术链接）。
- 各渠道话术草稿（微信长文 / 企微卡片文案 / 短信短句 / 电话要点）。
- 频率与防骚扰阈值说明（合规护栏）。
- 一份「待商务确认」清单（HITL）。

## Guardrails
- 所有对外发送**只出草稿**，需商务 / 合规确认后方可落地（HITL）。
- 遵守短信与电话外呼合规：提供退订路径、限定时段、不得骚扰。
- 不伪造触达数据（打开率 / 回复），不夸大政策收益。
- 客户联系方式与回复内容仅用于本次任务，不出域、不留存。

## Notes
- 可配合 `distributor-onboarding`（入驻欢迎 / 首单催办）与 `channel-inspection`（低活跃客户唤醒）联动。
- 真实触达执行由分销 SaaS 的通道层完成；本技能负责编排与文案，不直接调用短信网关。
