# 观众运营与数据复盘（Audience Growth）

## When to use
- 新观众进来留不住，次日 / 7 日留存低。
- 老粉丝沉默、粉丝团活跃度下滑、活动没人响应。
- 直播数据"只涨粉不涨转化"，GMV / 打赏 / 互动不达标。
- 社区想做主题日、连麦专场、粉丝节等增长活动，缺方案与抓手。

## Steps
1. **用户分层**：按行为把观众分为新客 / 活跃 / 沉默 / 高价值 / 粉丝团，标注每层的运营目标与触点。
2. **留存与召回**：为新客设计首播后承接（社群 / 私信 / 专属权益），为沉默用户设计召回触达（福利 / 内容钩子），全部走 HITL 草稿。
3. **活动运营**：设计主题日 / 连麦专场 / 粉丝节等活动的目标、玩法、节奏与履约话术，明确合规边界。
4. **数据复盘**：围绕观看时长、留存曲线、互动率、转化（GMV / 打赏 / 关注）做漏斗分析，定位缺失环节。
5. **增长建议**：从「内容杠杆 / 时段杠杆 / 互动杠杆」三处给可执行建议，反哺选题与排期。

## Output
- 一份《用户分层运营方案》Markdown（分层 / 目标 / 触点 / 动作）。
- 一份召回 / 留存触达草稿（社群 + 私信话术）。
- 一套活动方案模板（目标 / 玩法 / 节奏 / 履约）。
- 一份《直播数据复盘报告》（漏斗 + 缺口 + 建议）。

## Guardrails
- 召回 / 触达只出草稿，需运营确认后由合规通道执行，避免骚扰式群发。
- 活动福利与价格须真实可履约，不诱导非理性消费、不涉未成年人。
- 观众数据仅用于本次运营，不出域、不外流。
