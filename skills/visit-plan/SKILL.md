# 拜访计划编排（Visit Plan）

## When to use
- 周 / 月拜访排程，业务员不知道先跑谁、跑什么。
- 红黄渠道客户需要优先线下跟进（见 `channel-inspection`）。
- 新经销商首月需要高频陪跑。
- 大客户续约 / 扩品节点需要专项拜访。

## Steps
1. **汇集拜访对象**：结合渠道巡检结果、签约节点、动销与回款状态，生成本周期候选名单。
2. **评分优先级**：优先级 = 产出潜力 × 风险等级 × 时效紧迫度；红黄客户、首月新客、续约节点加权。
3. **排线路径与时段**：按地理就近 + 时段可达（避开客户繁忙）生成每日路线，控制单日拜访上限。
4. **生成每点目标与话术要点**：每个客户给 1 个核心目标（催款 / 铺货 / 培训 / 续约）+ 3 句开场与异议处理要点。
5. **输出日程**：《拜访日程表》含客户、时间、路线、目标、需带资料，交业务员确认。

## Output
- 《拜访日程表》Markdown（日 × 客户 × 时段 × 路线 × 目标）。
- 每点话术要点（开场 / 核心诉求 / 异议处理 / 收尾）。
- 路线优化说明（里程 / 时间节省）。
- 一份「待业务员确认」清单（HITL）。

## Guardrails
- 路线与排程**只出建议**，最终以业务员实际为准。
- 不擅自向客户承诺价格 / 政策，承诺需商务授权。
- 客户地址与联系人属隐私，仅用于本次排程，不出域。

## Notes
- 可配合 `channel-inspection`（红黄客户优先排）与 `reach-campaign`（拜访后补触达）联动。
