# 直播间互动运营（Live Room Ops）

## When to use
- 主播开播但弹幕冷场、互动靠临场发挥。
- 礼物 / 打赏感谢节奏混乱，高价值用户未被识别与维护。
- 抽奖、连麦、粉丝团活动缺乏规则与脚本。
- 直播中出现黑屏、引战、违规观众等突发状况，处置无预案。

## Steps
1. **设计互动节奏**：按「开场暖场 → 核心内容 → 高潮转化 → 收尾沉淀」埋互动节点（欢迎、提问、投票、任务）。
2. **弹幕 / 评论运营**：生成欢迎语、关键词应答（价格 / 链接 / 福利）、控评与引导话术，区分新客与老粉。
3. **礼物 / 打赏运营**：设计感谢节奏与任务式打赏（达成目标解锁福利），标注打赏限额与合规提示，识别并维护高价值用户。
4. **活动脚本**：抽奖 / 连麦 / 粉丝团升级的活动规则、口令、中奖与履约话术，避免歧义与纠纷。
5. **突发处置预案**：黑屏 / 卡顿、引战带节奏、违规观众、敏感词触发的分级处置（提醒 / 拉黑 / 关播），给出主播与运营分工。

## Output
- 一份《互动脚本》Markdown（按时间轴 / 节点排布）。
- 一个话术库（欢迎 / 应答 / 感谢 / 控评 / 履约）。
- 一套活动规则模板（抽奖 / 连麦 / 粉丝团）。
- 一份《直播间应急 SOP》（突发分类 → 处置动作 → 责任人）。

## Guardrails
- 所有话术与活动只出草稿，由主播 / 运营定稿与执行，不自动发送、不自动操作直播间。
- 打赏 / 抽奖须合规（限额、明示规则、防未成年人参与），不诱导非理性消费。
- 处置违规观众须有证据、有梯度，避免误伤与平台规则冲突。

## Notes
- 可配合 `live-show-plan`：每场直播的互动脚本由排期驱动生成。
- 可配合 `community-moderation`：违规判定标准与处置话术两技能对齐。
- 互动数据（停留 / 礼物 / 转化）回流 `audience-growth` 做复盘。
