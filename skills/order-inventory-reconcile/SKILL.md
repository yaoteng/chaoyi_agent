# 订单库存对账（Order & Inventory Reconcile）

## When to use
- 月结 / 季结需要对齐四流（订单 / 出库 / 库存 / 回款）。
- 客户投诉「发了没收到」「库存对不上」。
- 资金盘点发现长账期应收或疑似坏账。
- 大促前后需要清库存、防缺货。

## Steps
1. **拉取四流数据**：订单明细、出库 / 发货记录、当前库存、回款流水。
2. **逐单对账找差异**：标记未发货订单、已发未收（在途）、负库存、超卖、回款缺失。
3. **标记缺货与资金风险**：低库存 SKU 预警；账期 > 阈值的应收标红；同一客户多笔异常聚合成风险档案。
4. **生成对账报告**：差异表 + 缺货清单 + 回款风险清单 + 跟进待办。
5. **产出跟进动作**：谁负责催办、谁负责调货、谁负责财务复核，交相关人确认。

## Output
- 《对账差异表》Markdown（订单 × 状态 × 差异类型 × 金额）。
- 缺货预警清单（SKU × 可用库存 × 在途 × 建议补货）。
- 回款风险清单（客户 × 账期 × 金额 × 等级）。
- 一份「待财务 / 商务确认」清单（HITL）。

## Guardrails
- 财务 / 库存数据高度敏感，仅用于本次对账，不出域、不留存。
- **不**直接改账、不擅自冲销，差异须财务复核后处理。
- 缺货 / 坏账结论须基于真实数据，不得推测夸大。

## Notes
- 可配合 `channel-inspection`（对账差异佐证渠道异常根因）联动。
