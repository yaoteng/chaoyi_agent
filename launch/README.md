# 冲星战役执行包（launch/）

> 本目录是「潮驿 Agent 一周千星」的**可操作执行包**。战略与测算见根目录 `潮驿Agent一周千星战术战略书.md`，本文档是落地动作集。

## 目录
| 文件 | 用途 |
|---|---|
| `runbook.md` | **每日作战手册**：Gate 检查 → D-1 备料 → D0–D6 逐日动作 + 应急 + 合规 |
| `posts/01_juejin.md` | 掘金长文（D0） |
| `posts/02_oschina.md` | 开源中国 OSChina（D0） |
| `posts/03_zhihu.md` | 知乎（D0） |
| `posts/04_showhn.md` | Show HN（D1） |
| `posts/05_reddit.md` | Reddit（D1） |
| `posts/06_devto.md` | Dev.to（D1） |
| `posts/07_x_thread.md` | X 长线程（D2） |
| `posts/08_wechat.md` | 微信公众号（D2） |
| `posts/09_xiaohongshu.md` | 小红书（D5） |
| `posts/10_producthunt.md` | Product Hunt（D5） |
| `demo-script.md` | 30 秒演示视频分镜脚本 |
| `kpi-tracker.md` | 每日 KPI 追踪表（填空用） |

## 使用顺序
1. **推送代码到已建好的仓库**：本机 `gh auth login` 后，把本目录推送到 `yaoteng/chaoyi_agent`（仓库已创建、当前为空，需要首次 push）。
2. **D-1**：读 `runbook.md` 第 2 节，把 `posts/` 各篇复制进对应平台草稿箱。
3. **D0–D6**：按 `runbook.md` 第 3 节逐日执行，每天 22:00 在 `kpi-tracker.md` 填一行。
4. **全程**：遵守 `runbook.md` 第 4–5 节应急与合规红线。
