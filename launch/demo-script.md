# 30 秒演示视频脚本 · 潮驿 Agent

> 目的：让访客 30 秒内理解"这是什么 + 对我有什么用"。建议用屏幕录制（OBS / 录屏）→ 剪映加字幕。

## 分镜（总时长 ~30s）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–3s | 黑底白字：「一个 1–2 千家门店的快消分销商，运营要花多少工时？」 | 一个中等规模分销商，运营有多累？ |
| 3–8s | 切到云栈分销样例 README，高亮"月运营 ~40h" | 传统做法：经销商反复补资料、政策群发打开率个位数、月底拉表才发现红黄客户… ≈ 40 小时/月 |
| 8–18s | 终端里对智能体说：「给华东区账期超 60 天的经销商排一轮回款催办触达，3 波、各渠道话术、24h 同渠道去重」；屏幕快速闪过 `skills/reach-campaign` 与 `skills/order-inventory-reconcile` 的 SKILL.md | 现在：装一套潮驿 Skill，对智能体说一句话，自动编排触达、对账、排程 |
| 18–25s | 输出对比表：40h → 6h；出现 `chaoyi_agent` 仓库页面 + 5 个 Skill 卡片 | 月工时从 40h 降到 6h。5 个开箱即用分销 Skill，MIT 开源 |
| 25–30s | 收尾字幕 + 仓库地址 + 「让每个分销团队都拥有数字业务社工」 | 潮驿 Agent · 让每个分销团队都拥有自己的数字业务社工 |

## 录制要点
- 用 `examples/reference-distribution/` 作为演示素材（已写好剧本，可直接照着跑）。
- 关键动作要"慢一点、清晰一点"：打开 `skills/` 目录、展示一个 `SKILL.md` 的 frontmatter（name/description/兼容标准）。
- 结尾字幕停留 ≥3s，确保地址可读。
- 导出：横屏 1080p，同时截一帧做封面/小红书图。

## 一句 slogan（各平台通用）
> 潮驿 Agent：5 个开源 Skill，让分销团队月运营工时从 40h 降到 6h。MIT · 跨宿主 · 兼容 Skills 1.0 + MCP 0.4。
