# 30 秒演示视频脚本 · 潮驿 Agent

> 目的：让访客 30 秒内理解"这是什么 + 对我有什么用"。建议用屏幕录制（OBS / 录屏）→ 剪映加字幕。

## 分镜（总时长 ~30s）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–3s | 黑底白字：「一个 2.3k star 的小开源社群，运营要花多少工时？」 | 一个 2.3k star 的小社群，运营有多累？ |
| 3–8s | 切到 RustyCache 样例 README，高亮"月运营 ~40h" | 传统做法：每周分类 issue、写发布说明、做本地化、致谢贡献者… ≈ 40 小时/月 |
| 8–18s | 终端里对智能体说：「帮我把本周 issue 分类并起草回复 + 生成 v0.4 发布说明」；屏幕快速闪过 `skills/issue-triage` 与 `skills/release-notes` 的 SKILL.md | 现在：装一套潮驿 Skill，对智能体说一句话，自动分类、起草、发布 |
| 18–25s | 输出对比表：40h → 6h；出现 `chaoyi_agent` 仓库页面 + 5 个 Skill 卡片 | 月工时从 40h 降到 6h。5 个开箱即用社群 Skill，MIT 开源 |
| 25–30s | 收尾字幕 + 仓库地址 + 「让每个小社群都拥有数字社工」 | 潮驿 Agent · 让每个小社群都拥有自己的数字社工 |

## 录制要点
- 用 `examples/reference-community/` 作为演示素材（已写好剧本，可直接照着跑）。
- 关键动作要"慢一点、清晰一点"：打开 `skills/` 目录、展示一个 `SKILL.md` 的 frontmatter（name/description/兼容标准）。
- 结尾字幕停留 ≥3s，确保地址可读。
- 导出：横屏 1080p，同时截一帧做封面/小红书图。

## 一句 slogan（各平台通用）
> 潮驿 Agent：5 个开源 Skill，让小社群月运营工时从 40h 降到 6h。MIT · 跨宿主 · 兼容 Skills 1.0 + MCP 0.4。
