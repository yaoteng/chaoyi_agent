# 30 秒演示视频脚本 · 潮驿 Agent

> 目的：让访客 30 秒内理解"这是什么 + 对我有什么用"。建议用屏幕录制（OBS / 录屏）→ 剪映加字幕。

## 分镜（总时长 ~30s）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–3s | 黑底白字：「一个 300+ 主播的直播社区，运营要花多少工时？」 | 一个中等规模直播社区，运营有多累？ |
| 3–8s | 切到食光小馆直播社区样例 README，高亮"月运营 ~40h" | 传统做法：主播反复补资料、推流配置卡壳、选题撞车、弹幕冷场、违规靠人工刷… ≈ 40 小时/月 |
| 8–18s | 终端里对智能体说：「给新签的 3 个美食主播按 streamer-onboarding 生成入驻阶梯，并衔接首播排期」；屏幕快速闪过 `skills/streamer-onboarding` 与 `skills/live-room-ops` 的 SKILL.md | 现在：装一套潮驿 Skill，对智能体说一句话，自动编排入驻、策划、互动、风控 |
| 18–25s | 输出对比表：40h → 6h；出现 `chaoyi_agent` 仓库页面 + 5 个 Skill 卡片 | 月工时从 40h 降到 6h。5 个开箱即用直播社区 Skill，MIT 开源 |
| 25–30s | 收尾字幕 + 仓库地址 + 「让每个直播社区都拥有数字社工」 | 潮驿 Agent · 让每个直播社区都拥有自己的数字社工 |

## 录制要点
- 用 `examples/reference-livestream/` 作为演示素材（已写好剧本，可直接照着跑）。
- 关键动作要"慢一点、清晰一点"：打开 `skills/` 目录、展示一个 `SKILL.md` 的 frontmatter（name/description/兼容标准）。
- 结尾字幕停留 ≥3s，确保地址可读。
- 导出：横屏 1080p，同时截一帧做封面/小红书图。

## 一句 slogan（各平台通用）
> 潮驿 Agent：5 个开源 Skill，让直播社区月运营工时从 40h 降到 6h。MIT · 跨宿主 · 兼容 Skills 1.0 + MCP 0.4。
