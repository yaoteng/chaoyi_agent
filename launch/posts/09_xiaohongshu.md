**封面**：维护开源项目月运营 40h ⏩ 6h，我做对了什么？

**正文**：
谁懂啊😭 自己搞了个开源小项目，star 没涨多少，人先被运营杂活累瘫了——

每周几十个 issue 要回、发版要写说明、文档要翻英文、贡献者要记得谢……一个月 40 小时没了，比上班还累💀

直到我给社群装了一套"数字社工"👉 潮驿 Agent

🌟 5 个开箱即用 Skill：
1️⃣ 贡献者入驻引导
2️⃣ issue 管家（自动分类+起草回复）
3️⃣ 发布说明生成
4️⃣ 文档一键本地化
5️⃣ 贡献致谢墙

💡 用法超简单：把 skills 目录丢给 Cursor/Claude，说一句"帮我分类本周 issue 并写发布说明"，搞定。

✅ 兼容 Skills 1.0 + MCP 0.4，主流智能体都能跑
✅ 纯 SKILL.md，MIT 开源，零依赖，fork 就能改
✅ 自带 Rust 社群样例，手把手演示 40h→6h

👉 搜 GitHub：chaoyi_agent（或直接搜"潮驿 Agent"）
⭐ 顺手点个 star，第六个 Skill 等你来写～
