**Name**: Chaoyi Agent

**Tagline**: Open-source Skills that give your community a digital volunteer

**Description (first paragraph)**:
Chaoyi Agent is a cross-host open-source Skill library that helps small open-source / developer communities become "agent-assisted" without building any infra. Ship 5 ready-to-use Skills: contributor onboarding, issue triage, release notes, doc localization, and contributor recognition. Compatible with Skills 1.0 + MCP 0.4; runs in Claude Code, Cursor, WorkBuddy, Codex. MIT licensed, zero-dependency, fork-and-edit. Includes a full worked example showing monthly ops drop from ~40h to ~6h.

**First Comment (Maker comment)**:
Hi PH 👋 I'm the maintainer. The pain I kept hitting: not coding, but community ops — triaging issues, writing release notes, translating docs, thanking contributors. Chaoyi is a set of plain SKILL.md files that turn your existing agent into a "digital volunteer" for exactly that. MIT, no lock-in. Would love feedback on which 6th Skill to add next!
