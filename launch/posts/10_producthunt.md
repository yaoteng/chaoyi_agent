**Name**: Chaoyi Agent

**Tagline**: Open-source Skills that give your live-streaming community a digital community worker

**Description (first paragraph)**:
Chaoyi Agent is a cross-host open-source Skill library that helps small live-streaming communities become "agent-assisted" without building any infra. Ship 5 ready-to-use Skills: streamer onboarding, live-show planning, live-room interaction ops, community moderation, and audience growth. Compatible with Skills 1.0 + MCP 0.4; runs in Claude Code, Cursor, WorkBuddy, Codex. MIT licensed, zero-dependency, fork-and-edit. Includes a full worked example showing monthly ops drop from ~40h to ~6h.

**First Comment (Maker comment)**:
Hi PH 👋 I'm the maintainer. The pain I kept hitting: not signing big streamers, but community ops — onboarding streamers, planning shows, running live-room interactions, moderating content, growing the audience. Chaoyi is a set of plain SKILL.md files that turn your existing agent into a "digital community worker" for exactly that. MIT, no lock-in. Would love feedback on which 6th Skill to add next!
