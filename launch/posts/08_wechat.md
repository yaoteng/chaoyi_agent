# 我给直播社区装了"数字社工"，月运营工时从 40 小时降到 6 小时

你有没有过这种体验：

直播社区铺得挺开心，结果一个月下来全在——

- 给新主播反复补资料、卡推流配置、带首播、做培训
- 直播频次靠主播自觉，选题撞车、预告缺失、切片没人剪
- 直播间弹幕冷场、高价值观众没被接住、抽奖连麦没规则
- 违规内容靠人工刷，举报石沉大海，直播实时风控空白
- 观众留不住、老粉沉默、活动没声量，数据只涨粉不涨转化

带一个小直播社区，这些"杂活"一个月能吃掉 40 个小时。比谈主播累多了。

## 我做了个东西

叫 **潮驿 Agent（Chaoyi Agent）**，说人话就是：给直播社区装一组"数字社工"Skill。

首发 5 个，开箱即用：
- 主播入驻引导（签约→实名资质→推流配置→首播策划→培训）
- 直播内容策划（选题库 / 排期 / 脚本 / 多平台分发）
- 直播间互动运营（弹幕 / 礼物 / 抽奖 / 连麦 / 粉丝团）
- 社区内容风控（违规判定 / 五档处置 / 举报闭环 / 合规红线）
- 观众运营复盘（分层 / 召回 / 活动 / 数据复盘）

## 怎么用？

把 `skills/` 目录交给你的智能体（Cursor / Claude Code / 通义 / CodeBuddy 都行），对它说一句：

> "给新签的 3 个美食主播按 streamer-onboarding 生成入驻阶梯，并衔接首播排期"

它就调用对应 Skill，把结果直接给你，复制粘贴即可。

## 为什么值得关注

- 兼容 Skills 1.0 + MCP 0.4，**主流智能体都能跑**
- 纯 SKILL.md + 模板，**MIT 开源、零依赖、fork 即改**
- 自带一个完整样例：一个虚构美食直播社区"食光小馆直播社区"，演示 40h→6h 是怎么做到的
- 内置合规红线：未成年人保护、打赏限额、版权曲库、内容安全审核
