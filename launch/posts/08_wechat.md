# 我给分销团队装了"数字业务社工"，月运营工时从 40 小时降到 6 小时

你有没有过这种体验：

快消分销生意铺得挺开心，结果一个月下来全在——

- 给新经销商反复补资料、追资质、跟培训、推首单
- 政策 / 活动 / 回款催办群发，打开率个位数，只能硬打电话
- 月底拉渠道表才发现红黄客户早该流失预警
- 月结对账两人花三天，还常有"发了没收到"的扯皮
- 业务员拜访凭感觉，谁先跑、进门说什么全靠经验

带一个小分销团队，这些"杂活"一个月能吃掉 40 个小时。比谈客户累多了。

## 我做了个东西

叫 **潮驿 Agent（Chaoyi Agent）**，说人话就是：给分销团队装一组"数字业务社工"Skill。

首发 5 个，开箱即用：
- 经销商入驻引导（签约→资质→开通→培训→首单）
- 多渠道触达编排（微信/企微/短信/电话，节奏+话术）
- 渠道健康巡检（动销/库存/回款/窜货打分）
- 订单库存对账（订单/出库/库存/回款四流对账）
- 拜访计划编排（路线+话术要点）

## 怎么用？

把 `skills/` 目录交给你的智能体（Cursor / Claude Code / 通义 / CodeBuddy 都行），对它说一句：

> "给华东区账期超 60 天的经销商排一轮回款催办触达，3 波、各渠道话术、24h 同渠道去重"

它就调用对应 Skill，把结果直接给你，复制粘贴即可。

## 为什么值得关注

- 兼容 Skills 1.0 + MCP 0.4，**主流智能体都能跑**
- 纯 SKILL.md + 模板，**MIT 开源、零依赖、fork 即改**
- 自带一个完整样例：一个虚构快消分销商"云栈分销"，演示 40h→6h 是怎么做到的
- 内置合规红线：不绕过短信/外呼合规、不伪造经营数据、不骚扰式群发

仓库在这：https://github.com/yaoteng/chaoyi_agent
