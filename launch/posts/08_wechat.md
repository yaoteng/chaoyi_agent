# 我给开源社群装了"数字社工"，月运营工时从 40 小时降到 6 小时

你有没有过这种体验：

开源项目代码写得挺开心，结果一周下来全在——

- 给几十个 issue 分类、贴标签、回消息
- 发版前憋一篇 release notes
- 把中文文档翻译成英文
- 翻记录想起来要谢谢谁

一个人维护小社群，这些"杂活"一个月能吃掉 40 个小时。比写代码累多了。

## 我做了个东西

叫 **潮驿 Agent（Chaoyi Agent）**，说人话就是：给社群装一组"数字社工"Skill。

首发 5 个，开箱即用：
- 贡献者入驻引导
- issue 管家（分类 + 起草回复）
- 发布说明生成
- 文档本地化
- 贡献致谢墙

## 怎么用？

把 `skills/` 目录交给你的智能体（Cursor / Claude Code / 通义 / CodeBuddy 都行），对它说一句：

> "帮我把本周 issue 分类并起草回复，再生成 v0.4 发布说明"

它就调用对应 Skill，把结果直接给你，复制粘贴即可。

## 为什么值得关注

- 兼容 Skills 1.0 + MCP 0.4，**主流智能体都能跑**
- 纯 SKILL.md + 模板，**MIT 开源、零依赖、fork 即改**
- 自带一个完整样例：一个 Rust 工具库社群，演示 40h→6h 是怎么做到的

仓库在这：https://github.com/yaoteng/chaoyi_agent

如果你也在被社群运营拖垮，欢迎来 star、来提 PR——第六个垂类 Skill，等你来写。
