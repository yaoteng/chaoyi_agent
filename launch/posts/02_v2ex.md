最近把维护开源项目的杂活（issue 分类、写发布说明、本地化、致谢）用一组开源 Skill 自动化了，月运营工时从 ~40h 降到 ~6h。

项目叫 **潮驿 Agent（Chaoyi Agent）**，定位不是又一个 Agent 框架，而是"帮社群低成本 agent 化"的工具箱：

- 首发 5 个社群 Skill：入驻引导 / issue 管家 / 发布说明 / 文档本地化 / 贡献致谢
- 兼容 Skills 1.0 + MCP 0.4，Claude Code / Cursor / WorkBuddy / Codex 都能直接跑
- 纯 SKILL.md + 模板，MIT，零依赖，fork 即改
- 自带一个完整样例（Rust 工具库），演示怎么把运营工时压下来

仓库：https://github.com/yaoteng/chaoyi_agent

欢迎拍砖，也欢迎提 PR 加第六个垂类 Skill。
