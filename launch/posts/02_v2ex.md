最近把快消分销团队的运营杂活（经销商入驻、政策触达、渠道巡检、订单对账、拜访排程）用一组开源 Skill 自动化了，月运营工时从 ~40h 降到 ~6h。

项目叫 **潮驿 Agent（Chaoyi Agent）**，定位不是又一个 Agent 框架，而是"帮分销业务低成本 agent 化"的工具箱：

- 首发 5 个分销 Skill：经销商入驻引导 / 多渠道触达编排 / 渠道健康巡检 / 订单库存对账 / 拜访计划编排
- 兼容 Skills 1.0 + MCP 0.4，Claude Code / Cursor / WorkBuddy / Codex 都能直接跑
- 纯 SKILL.md + 模板，MIT，零依赖，fork 即改
- 自带一个完整样例（虚构快消分销商"云栈分销"），演示怎么把运营工时压下来

仓库：https://github.com/yaoteng/chaoyi_agent

欢迎拍砖，也欢迎提 PR 加第六个垂类分销 Skill。
