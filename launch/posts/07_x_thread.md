**主推（1/7）**  
维护小开源社群最累的不是写代码，是运营杂活：  
issue 分类、写发布说明、文档翻译、感谢贡献者……  
我们把它压到了 1/7 的工时 👇

**2/7** 我们做了 @chaoyi_agent：一组跨宿主开源 Skill，专门给社群做 "agent 化改造"。首发 5 个即用 Skill。

**3/7** 🧭 community-onboarding — 自动生成贡献者入驻引导  
🗂 issue-triage — issue 分类 + 起草回复 + 标 good-first-issue  
📝 release-notes — 从 commit 生成发布说明

**4/7** 🌐 doc-localization — 文档多语言本地化  
🏅 contributor-recognition — 自动汇总贡献、生成致谢墙  
全部纯 SKILL.md + 模板，MIT，零依赖。

**5/7** 关键：兼容 Skills 1.0 + MCP 0.4，Claude Code / Cursor / WorkBuddy / Codex 直接跑。不是又一个框架，是把"已有社群"低成本 agent 化。

**6/7** 仓库自带完整样例：一个 Rust 工具库社群，演示月运营工时 40h → 6h。  
👉 <https://github.com/yaoteng/chaoyi_agent>

**7/7** 如果你也在维护小社群：评论区说说最痛的运营杂活，我挑 3 个送定制 Skill 草稿。⭐️ 欢迎 star & PR。
